## 🚀 Featured Projects

### Azir
Open-source LLM gateway and intelligent routing layer for multiple model providers.

- OpenAI-compatible `/v1/chat/completions` API
- OpenAI and Anthropic provider support
- Streaming and non-streaming responses
- Capability-, cost-, and quality-aware routing
- Provider fallback and error normalization
- Token usage, latency, and cost telemetry
- Extensible provider and model registry architecture

**Tech:** Python, FastAPI, Pydantic, httpx, OpenAI, Anthropic, PostgreSQL, Docker, pytest

[View Azir on GitHub](https://github.com/aadithyamuthukumar/azir)

### CineBuff
Movie recommendation backend supporting a catalog of 20,000+ movies.

- FastAPI APIs for chat, retrieval, ingestion, embeddings, and recommendations
- PostgreSQL + pgvector semantic search
- HNSW indexing and popularity-aware reranking
- Persistent multi-turn recommendation state
- Asynchronous service architecture

**Tech:** Python, FastAPI, PostgreSQL, pgvector, RAG, REST APIs

### docs-mcp
MCP-based documentation retrieval system for FastAPI documentation.

- Indexed 148 documentation pages into 793 searchable chunks
- Voyage AI embeddings for semantic retrieval
- Hybrid lexical + vector search
- Reciprocal Rank Fusion for improved ranking
- MCP interface for providing documentation context to AI agents

**Tech:** Python, FastMCP, SQLite, Voyage AI, Vector Search
